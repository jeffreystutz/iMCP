# Third-Party Notices

## mac_messages_mcp

The direct Apple Messages automation in `App/Services/MessagesSender.swift` was
adapted in part from
[`mac_messages_mcp`](https://github.com/carterlasalle/mac_messages_mcp) by
Carter LaSalle. The iMCP implementation was redesigned for native Swift,
in-process Apple Event descriptors, explicit confirmation, sandboxing, and
single-attempt dispatch, but retains attribution to the project that informed
the original send behavior.
